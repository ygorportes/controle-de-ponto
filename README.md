
# Sistema de Controle de Ponto

Projeto simples de controle de ponto desenvolvido em Java, para registrar entrada e saída de funcionários e calcular as horas trabalhadas. Os registros são armazenados em um arquivo JSON.


## Funcionalidades

- Registrar entrada e saída de funcionários.
- Mostrar relatório com o nome, entrada, saída e horas trabalhadas.
- Armazenar os registros em JSON.
